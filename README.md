# Controlled Source Intervention for Empirical Validation of Static-Analysis Findings.

This research project presents a controlled source-intervention method for empirically studying static security-analysis findings. The approach applies targeted source changes to candidate program conditions, validates the modified source, reruns the static analyzer, and compares the resulting findings. A prototype implementation is evaluated on five manually constructed Python benchmarks using Bandit, focusing on the B105 and B608 security checks. The results demonstrate the feasibility of using controlled source interventions as a repeatable way to investigate static-analysis findings, while also highlighting the limitations of small, manually constructed benchmarks and the need for larger real-world evaluations.
